## Apa ini

**Mas Kiplay** adalah agent AI mobile satu-file (`index.html`) yang jalan sebagai PWA dan APK. Bukan chatbot manis. Ini alat kerja brutal: bongkar sistem, tulis kode semua bahasa, analisa market, jalankan alur perangkat yang didukung melalui izin eksplisit.

Semua fitur AI lewat OpenRouter — ratusan model gratis, kunci milik lu sendiri.

## Fitur

| Fitur | Keterangan |
|---|---|
| 🎙 **Jarvis** | Latar video senyap, hologram telinga saat mendengar, animasi mulut saat TTS, sapaan otomatis |
| 💬 **Chat** | Output teks detail, blok kode bisa disalin, upload gambar/dokumen |
| 🤖 **Agent** | Shell, Termux, buka app, browser, galeri, kamera, alarm |
| 📖 **Al-Qur'an** | 114 surat, Arab + latin + arti Indonesia + audio |
| 🧪 **Cyber Lab** | Google Dork Builder, DNS over HTTPS, inspeksi header (CORS-limited), JWT decoder, SHA-256/384/512, Base64, URL codec |
| 🧰 **Toolkit** | QR, konversi, stopwatch, undian |
| 👤 **Profil** | Nama, usia, foto — dikenali AI |
| 🧬 **Evolusi** | AI merancang fitur baru sendiri |
| 📴 **Offline** | Service worker cache penuh |

## Catatan keamanan dan izin

- Fitur agent/command dinonaktifkan secara default. Aktifkan hanya saat memahami perintah yang akan dijalankan.
- Informasi perangkat yang dibaca dibatasi pada model, versi Android, CPU, RAM, dan ruang penyimpanan yang tersedia untuk aplikasi.
- Cyber Lab ditujukan untuk audit aset sendiri atau yang telah mendapat izin. Pemeriksaan HTTP dapat dibatasi kebijakan CORS.
- SMS, isi WhatsApp, log panggilan, kendali game, dan otomasi UI penuh bukan fitur yang dijanjikan oleh rilis ini. Akses Android memerlukan implementasi native, izin terpisah, dan konfirmasi pengguna.

## Pasang

**APK** — unduh di [Releases](https://github.com/jambudio336-hue/Anime-artificial-intelejen-/releases/latest), izinkan *install unknown sources*.

**PWA** — buka halaman GitHub Pages, menu browser → *Add to Home screen*.

## Kunci API

1. Buka `https://openrouter.ai/keys`
2. Daftar (gratis, tanpa kartu)
3. Create Key → tempel di aplikasi
